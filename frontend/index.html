GERMANTRIS

Die deutsche Version von Semantris – ein Wort Assoziations Spiel angetrieben von einem fine-tuned Machine Learning Modell. Gebe ein Wort ein und siehe wie das Modell, die Wörter nach ihrer semantischen Ähnlichkeit zum eingegeben Wort sortiert. Es handelt sich hier um ein Open-Source Projekt, somit können Sie den Source Code im GitHub Repo aufrufen.
